

# T-Minus-Case

<img width="653" height="661" alt="Photo" src="https://github.com/user-attachments/assets/dd471734-2720-495e-a2a2-8dd26dec49c8" />

Metalic Case for The E-ink smartwatch Yatchy.

Here you'll find in depth information to manufacture top and bottom case, internal spacers, isolating layers for the internals and buttons.

---

##  Repository Structure

Inside this repository i have made available blueprints with tolerances and GD&T, CAD, CAM and STLs Files, and manufactiring process specificiations for all parts. For purchased parts i will leave a link to purchase or get in contact with the given maker.

###  Parts List and Links:
*   **[Top Case](https://github.com/OffSetEyeBrow/T-Minus-Case/tree/main/Blueprints):** Machined, containing files and instructions on production
*   **[Bottom Case](https://github.com/OffSetEyeBrow/T-Minus-Case/tree/main/STEPs):** Machined, containing files and instructions on production
*   **[Internal Spacers](https://github.com/OffSetEyeBrow/T-Minus-Case/wiki):** 3D Printed (FDM), containing files and 3D printing parameters
*   **[Buttons](https://github.com/OffSetEyeBrow/T-Minus-Case/wiki):** 3D Printed (FDM), containing files and 3D printing parameters
*   **[Yatchy Board](https://github.com/OffSetEyeBrow/T-Minus-Case/wiki):** Link to the Github of the original creator, still getting updated at the moment of writing this
*   **[Watch Strap](https://github.com/OffSetEyeBrow/T-Minus-Case/wiki):** Purchased from Aliexpress, brushed stainless steel with butterfly lock

## Materials Used

My personal T- Case has been made with the following materials:

*   **Devices for Machining:** Polyurethane Blocks
*   **Top & Bottom Cases:** Aluminum 5083 (Machined)
*   **Internal Spacers:** 95A TPU Filament (3D Printed)
*   **Buttons:** Transparent PLA Filament (3D Printed)
