

# T-Minus-Case

Metalic Case for The E-ink smartwatch Yatchy.

Here you'll find in depth information to manufacture top and bottom case, internal spacers, isolating layers for the internals and buttons.

---

##  Repository Structure

Inside this repository, you will find:
*   **[Blueprints](https://github.com/bigman64therealone/T-Minus-Case/tree/main/Blueprints):** Technical Drawings with Tolerances and design information
*   **[CAD & CAM Files](https://github.com/bigman64therealone/T-Minus-Case/tree/main/STEPs):** Complete blueprints with tolerances and dimensions for machining.
*   **[Process Wiki](https://github.com/bigman64therealone/T-Minus-Case/wiki):** All Instructions Regarding Manufacturing (Machining and 3D printing) of the watch case

---

## Materials Used

My personal T- Case has been made with the following materials:

*   **Devices for Machining:** Polyurethane Blocks
*   **Top & Bottom Cases:** Aluminum 5083 (Machined)
*   **Internal Spacers:** 95A TPU Filament (3D Printed)
*   **Buttons:** Transparent PLA Filament (3D Printed)
